# From kirkstone habits to wrynose

My production Yocto work stayed on 4.0 "kirkstone", tied to a vendor BSP.
This repository starts on 6.0 "wrynose". These notes record what I wrote out
of kirkstone habit, what broke and how I fixed it.

Upstream reference: the migration guides for 4.1 through 6.0 in the
[Yocto Project documentation](https://docs.yoctoproject.org/migration-guides/).
